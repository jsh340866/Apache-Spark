모든 노드가 동일 경로로 마운트 — Standalone 클러스터는 분산 파일시스템이 없으므로, jobs · conf · data · logs를 전 노드가 /opt/spark-apps/... 동일 절대경로로 보도록 bind mount로 맞춰야 워커가 파일을 찾을 수 있습니다.
Jupyter는 별도 이미지 — 워커는 apache/spark:3.5.0(Python 3.8), Jupyter는 jupyter/pyspark-notebook(Python 3.11)이라 마이너 버전이 다릅니다. 노트북에서 spark.createDataFrame()으로 파이썬 객체를 워커에 보내면 PYTHON_VERSION_MISMATCH가 발생합니다 (미해결, pandas로 우회 중).

주요 설정 (conf/spark-defaults.conf)

설정값이유
spark.sql.shuffle.partitions 4 워커 총 4코어 기준. 21,870개 그리드 실행 시에는 64로 override 필요
spark.executor.memory 2g 미지정 시 기본 1g로 executor가 힙 부족으로 강제 종료(exitStatus 143)되는 것 실측
spark.sql.autoBroadcastJoinThreshold 10MB 전략 테이블(21,870행, 약 1.9MB) 브로드캐스트 조인으로 셔플 제거
spark.eventLog.dir logs/events 마운트된 경로에 기록해야 컨테이너 재생성 후에도 실패 원인 추적 가능
