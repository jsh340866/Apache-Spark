# feat: 멀티팩터 가치주 선별 시스템 구현

## 작업 범위

**[0단계] StockPriceCollector 벌크 전환**
- `StockPriceCollector.java` — 종목별 루프 제거, 날짜 1회 JSON 호출로 전환 (`numOfRows=4000`, `resultType=json`)
- `StockPriceXmlParser.java` — 삭제

**[1단계] Company 업종코드·업종명 수집**
- `Company.java` — `indutyCode`, `indutyNm` 컬럼 추가
- `DartCompanyCollector.java` — DART `/api/company.json` 호출 추가, `induty_code`·`induty_nm` 저장 (sleep 적용)

**[2단계] 지표 계산 확장**
- `StockIndicator.java` — `roa`, `momentum`, `fScore`, `epsGrowthRate`(`eps_growth_rate`) 컬럼 추가
- `Company.java` — `isFinancialIndustry()` 추가 (`induty_code` 앞 2자리 64/65/66 판정, F-Score 스킵·Top100 필터 예외에 공용 사용)
- `FinancialIndicatorService.java`
  - ROA: `netIncome / totalAssets * 100`
  - 모멘텀: `(1개월전 종가 - 12개월전 종가) / 12개월전 종가`
  - EPS성장률: `(당기 EPS - 전기 EPS) / |전기 EPS| * 100` (전기 EPS = 전년도 당기순이익 / 1년전 상장주식수)
  - Piotroski F-Score(0~9) 계산
    - 수익성(4): ROA>0 / 영업현금흐름>0 / ROA 전년대비 증가 / 영업현금흐름>순이익
    - 재무건전성(3): 부채비율 감소 / 유동비율 증가 / 신주 발행 없음
    - 운영효율성(2): 매출총이익률 증가 / 자산회전율 증가
    - 금융업(`isFinancialIndustry()`)은 유동비율·매출총이익률 등 항목 구조 자체가 안 맞아 계산 스킵 → `fScore = null`

**[3단계] DART 재무데이터 수집 확장**
- `FinancialStatement.java` — `operating_cash_flow`, `current_assets`, `current_liabilities` 컬럼 추가
- `DartFinancialCollector.java` — 동일 API 응답에서 위 3개 항목 추가 파싱

**[4단계] 멀티팩터 가치점수 계산**
- `Top100.java` — `score` Integer→Double 변경
- `Top100Service.java`
  - F-Score 기준 미달 기업 필터링 (6점 이상 통과)
    - 단, 금융업은 `fScore = null`이라 "미달"이 아니라 필터 예외로 통과 처리
  - 팩터별 백분위 정규화(0~1) → 가중합산
    - PER 25% / PBR 15% / ROE 20% / ROA 10% / 부채비율 15% / EPS성장률 5% / 모멘텀 10%
  - 기존 `percentileScore()` 제거 → `percentileFraction()`(0~1 반환)으로 교체

```
전체 종목 → F-Score 필터링 → 팩터별 백분위 정규화 → 가중합산 → TOP100 저장
```
