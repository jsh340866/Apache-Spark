# 업종코드(KSIC) 중분류 매핑 — 2026-07-02

## 배경

- `Company.induty_code`는 DART `company.json` API에서 받아오는 값인데, API 응답에는 코드값만 있고 업종명은 없음 (공식 개발가이드 확인: 항목명·설명 모두 "업종코드"만 표기).
- 실제 값은 통계청 **한국표준산업분류(KSIC) 제10차 개정** 코드이며, 회사마다 등록된 분류 깊이가 다름 (3자리 소분류 / 4자리 세분류 / 5자리 세세분류 혼재).
- 앞 2자리(중분류)는 깊이에 상관없이 항상 동일한 레벨이라, 업종 그룹핑용으로 쓰려면 `induty_code`의 앞 2자리만 잘라서 비교해야 함.

## 데이터 출처 검증 과정 (주의: 9차 개정 오탐 있었음)

1. 처음 KOSIS에서 받은 xlsx 파일 → 메타데이터 확인 결과 **"제9차 한국표준산업분류"**(2007~2017, 폐지됨)였음. 이 파일 기준으론 임대업이 `69`였는데, 우리 DB의 실제 값(롯데렌탈 `76110`, 쏘카 `76110` 등)과 안 맞음.
2. `FinanceData/KSIC` GitHub 저장소의 `KSIC_10.csv.gz`로 교체.
3. 통계청 공식 **"제10차 기준 한국표준산업분류 실무 적용 가이드북(2022)"** PDF 본문에서 "운용리스는 `76 임대업`에 분류"라는 문구로 최종 검증 완료 → `KSIC_10.csv.gz` 데이터가 맞는 10차 코드임을 확인.

## 아직 미반영

- 이 매핑은 아직 코드(Java)에는 반영 안 함. 문서 정리만 완료.
- 실제로 업종별 그룹핑(예: 4단계 팩터별 백분위 정규화를 업종 내에서 계산)이 필요해지면, `SUBSTRING(induty_code, 1, 2)`로 중분류를 추출해서 이 매핑을 코드에 반영하면 됨.
