## ✅ 적용 가능한 공식

### 1. Graham Number — 그레이엄 적정주가

```
Graham Number = √(22.5 × EPS × BPS)
저평가율 = (Graham Number - 현재가) / Graham Number × 100
```

- 그레이엄이 제시한 PER ≤ 15, PBR ≤ 1.5 두 조건을 하나의 적정주가로 압축한 공식
- 저평가율이 양수 → 저평가 / 음수 → 고평가
- 근거 데이터: `STOCK_INDICATOR.eps`, `STOCK_INDICATOR.bps` 이미 존재
- 한계: EPS < 0(적자 기업)이면 계산 불가 → 제외 처리 필요

#### Graham Number 도입 시 스코어링 방식 A (추천)

PBR과 Graham Number는 BPS를 공유 → PBR을 Graham Number 저평가율로 교체

| 지표 | 방향 | 점수 | 변화 |
|------|------|------|------|
| PER | 낮을수록 | 30점 | 25→30 |
| Graham Number 저평가율 | 높을수록 | 30점 | PBR 대체 |
| ROE | 높을수록 | 25점 | 유지 |
| 부채비율 | 낮을수록 | 15점 | 25→15 |
| **합계** | | **100점** | |

> 중복 제거 + 직관적 설명 가능 ("현재가가 적정주가보다 X% 싸다") — 추천

#### Graham Number 도입 시 스코어링 방식 B

PBR(자산가치)과 Graham Number(복합 적정주가)를 다른 정보로 보고 병렬 적용

| 지표 | 방향 | 점수 |
|------|------|------|
| PER | 낮을수록 | 25점 |
| PBR | 낮을수록 | 15점 |
| Graham Number 저평가율 | 높을수록 | 25점 |
| ROE | 높을수록 | 25점 |
| 부채비율 | 낮을수록 | 10점 |
| **합계** | | **100점** | |

> BPS 정보를 PBR과 Graham Number 양쪽에서 반영 — 자산가치를 더 강조할 때

---

### 2. ROA — 총자산수익률

```
ROA = 순이익 ÷ 자산총계 × 100
```

- ROE는 부채로 수치를 부풀릴 수 있지만 ROA는 그렇지 않음
- Piotroski F-Score 핵심 지표
- 근거 데이터: `FINANCIAL_STATEMENT.net_income`, `total_assets` 이미 존재

---

### 3. EPS 3년 성장률

```
EPS 성장률 = (최근 EPS / 3년 전 EPS)^(1/3) - 1
```

- 버핏 계열 핵심 퀄리티 필터 — 수익성의 지속성 판단
- 근거 데이터: `FINANCIAL_STATEMENT` 3개년 순이익 + 발행주식수 이미 존재
- 한계: 기준연도 EPS < 0이면 계산 불가

---

### 4. PEG Ratio

```
PEG = PER ÷ EPS 연간 성장률(%)
```

- PEG < 1: 성장성 대비 저평가 / PEG = 1: 성장성이 PER에 완전 반영
- 고PER 성장주를 가치투자 시각으로 평가할 때 유효
- 근거 데이터: 위 EPS 3년 성장률 계산 후 기존 PER과 조합
- 한계: EPS 성장률이 음수 또는 0이면 무의미

---

### 5. 배당수익률 (보류 중)

- `STOCK_INDICATOR.dividend_yield` 이미 존재
- 스코어링 편입 여부는 별도 논의 필요

## ⚠️ 부분 적용 가능

### Piotroski F-Score — 재무건전성 체크리스트

0~9점 정수 스코어. 항목별 조건 충족 시 1점.

| 항목 | 기준 | 적용 가능 여부 |
|------|------|--------------|
| 당기순이익 > 0 | 흑자 | ✅ 가능 |
| ROA 전년 대비 증가 | 수익성 개선 | ✅ 가능 |
| 부채비율 전년 대비 감소 | 재무 개선 | ✅ 가능 |
| 매출총이익률 개선 | 수익구조 개선 | ✅ 가능 |
| 자산회전율 개선 | 운영 효율 | ✅ 가능 |
| 영업현금흐름 > 0 | 현금 창출 | ⚠️ DART 수집 추가 시 가능 |
| 현금흐름 > 순이익 | 이익 질 (분식 감지) | ⚠️ DART 수집 추가 시 가능 |
| 유동비율 전년 대비 증가 | 유동성 개선 | ⚠️ DART 수집 추가 시 가능 |
| 신주 발행 없음 | 주주 희석 없음 | ⚠️ 자본총계/BPS 역산으로 근사 가능 |

- 현재 데이터로 9점 중 5점 항목 구현 가능
- DART에서 영업현금흐름·유동자산·유동부채 추가 수집 시 완전 구현 가능

## 개선 로드맵

### Phase 1 — 즉시 (현재 데이터)
- Graham Number 저평가율 추가 (방식 A 또는 B 선택)
- ROA, EPS 성장률 보조 지표로 추가

### Phase 2 — DART 추가 수집 후
- 영업현금흐름, 유동자산/부채 항목 추가
- F-Score 완전 구현 (9점 만점)

### Phase 3 — 구조 고도화
- 업종별 정규화 (금융주 별도 풀)
- PEG Ratio 기반 성장주 필터 옵션

## 현재 시스템 방어 논리

균등 가중(25/25/25/25)은 자의성이 없다는 점에서 설명하기 가장 쉬운 구조다.
가중치를 바꾸려면 백테스팅 결과 또는 명확한 투자 철학 합의가 선행되어야 한다.
