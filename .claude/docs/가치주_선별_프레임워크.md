# 가치주 선별 프레임워크 — 학술 연구 기반

> Fama-French, AQR, Jegadeesh & Titman 등 퀀트 투자 논문을 기반으로 정리한 4단계 프레임워크. 실제 기관의 구현 방식과 다를 수 있음.

---

## 전체 흐름

```
전체 상장 종목
    ↓  1단계: 유니버스 필터링   → 노이즈 종목 제거
    ↓  2단계: 멀티팩터 계산     → 가치·퀄리티·모멘텀 수치화
    ↓  3단계: 업종 내 정규화    → Z-score로 업종 편향 제거
    ↓  4단계: 가중 합산         → 최종 스코어 → TOP N 선별
```

---

## 1단계 — 유니버스 필터링

점수 계산 전에 의미 없는 종목을 먼저 제거한다.
아무리 정교하게 계산해도 이 단계가 없으면 이상 종목이 상위에 올라온다.

### 시가총액 하한선
유동성이 없는 초소형주는 스코어가 높아도 실제 매수 시 주가가 튀어버린다.
- **현재**: `STOCK_PRICE.mrkt_tot_amt` 이미 있음 → 코드 추가만 하면 됨
- **추가 필요 데이터 없음**

### 관리종목 제외
KRX가 상장폐지 위험 경고를 붙인 종목. 재무가 아직 나쁘지 않더라도 감사의견 문제로 지정된 경우 TOP100에 진입할 수 있어 신뢰도 문제가 생긴다.
- **API**: KRX (`data.krx.co.kr`) — 관리종목지정현황
- **키 현황**: `krx.api.key` 이미 있음, 해당 서비스 신청만 필요
- **현재 대안**: 연속 적자·자본잠식 기업은 ROE·PER null 처리로 자연 제외되는 경우가 많음

### 거래정지 제외
매매 자체가 중단된 종목. TOP100에 올라와도 사용자가 매수할 수 없다.
- **API**: KRX (`data.krx.co.kr`) — 거래정지현황
- **키 현황**: `krx.api.key` 이미 있음, 해당 서비스 신청만 필요
- **현재 대안**: 거래정지 시 주가 데이터가 들어오지 않아 스코어링 대상에서 자연 제외되는 경우가 많음

### 금융주 별도 풀 분리
은행·보험·증권은 부채비율이 구조적으로 900%+로, 일반 기업과 같은 기준으로 비교하면 무조건 하위권이다. 별도 유니버스로 분리해 내부에서만 상대 비교해야 한다.
- **API**: DART (`opendart.fss.or.kr`) — `/api/company.json`
- **현재 수집 항목**: corp_code, corp_name, corp_cls (KOSPI/KOSDAQ 구분)
- **추가로 가져와야 할 항목**: `induty_code`(업종코드), `induty_nm`(업종명)
- **키 현황**: `dart.api.key` 이미 있음, 기존 수집 로직에 필드 추가만 하면 됨

## 2단계 — 멀티팩터 계산

가치주 선별에 쓰이는 팩터는 3가지 카테고리. 단일 팩터보다 카테고리를 조합할수록 안정성이 높아진다.

### 가치 팩터 (Value) — "지금 얼마나 싸냐"

| 지표 | 공식 | 현재 상태 | 비고 |
|------|------|----------|------|
| PER | 주가 ÷ EPS | ✅ 수집 중 | |
| PBR | 주가 ÷ BPS | ✅ 수집 중 | |
| Graham Number | √(22.5 × EPS × BPS) | ✅ 계산 가능 | EPS·BPS 이미 있음 |
| EV/EBITDA | 기업가치 ÷ EBITDA | ❌ 불가 | 감가상각비·현금 데이터 없음 |

Graham Number 활용법:
```
저평가율 = (Graham Number - 현재가) / Graham Number × 100
양수 → 저평가 / 음수 → 고평가
```

### 퀄리티 팩터 (Quality) — "기업 자체가 좋은 회사냐"

| 지표 | 공식 | 현재 상태 | 비고 |
|------|------|----------|------|
| ROE | 순이익 ÷ 자본총계 | ✅ 수집 중 | |
| 부채비율 | 부채총계 ÷ 자본총계 | ✅ 수집 중 | |
| ROA | 순이익 ÷ 자산총계 | ✅ 계산 가능 | 재무데이터 이미 있음 |
| EPS 3년 성장률 | (최근EPS / 3년전EPS)^(1/3) - 1 | ✅ 계산 가능 | 3개년 재무 이미 있음 |
| 영업현금흐름 | — | ⚠️ 추가 수집 필요 | 아래 참고 |
| ROIC | — | ❌ 불가 | 투하자본 계산 불가 |

**영업현금흐름 수집 방법**:
- **API**: DART `fnlttMultiAcnt.json` — 현재 이미 호출 중인 API
- **현재**: 매출액·영업이익·순이익·자산·부채·자본 6개 항목만 저장하고 나머지는 버리고 있음
- **추가로 가져와야 할 항목**: `영업활동현금흐름`, `유동자산`, `유동부채`
- 같은 API 응답에 이미 포함되어 있어 엔티티 컬럼 추가 + pick() 한 줄만 추가하면 됨

### 모멘텀 팩터 (Momentum) — "주가가 오르는 방향이냐"

학계에서 가장 실증적으로 강한 팩터 중 하나. 가치 팩터만 쓰면 "싸지만 계속 내리는 종목(가치함정)"을 걸러내지 못한다.

```
12-1 모멘텀 = (1개월 전 종가 - 12개월 전 종가) / 12개월 전 종가
```

최근 1개월을 제외하는 이유: 단기 반전 효과 차단 (직전 달에 급등한 종목이 단기 조정받는 현상)

- **API**: 공공데이터포털 — `GetStockSecuritiesInfoService` (현재 수집 중)
- **현재 수집 항목**: 일별 종가(`clpr`), 시가(`mkp`), 등락률, 시가총액, 상장주식수
- **추가로 가져와야 할 항목 없음** — `STOCK_PRICE` 테이블에 이미 날짜별 종가 있음, 계산 로직만 추가하면 됨

## 3단계 — 업종 내 Z-score 정규화

실제 기관과 현재 우리 시스템의 가장 큰 차이점.

### 현재 우리 방식의 문제

```
전체 종목 PER을 낮은 순으로 줄 세워 0~25점 정수 부여
→ 반도체 업종 PER 30 vs 유틸리티 업종 PER 10 직접 비교
→ 유틸리티가 무조건 유리 (업종 특성 무시)
```

### 기관 방식 — 업종 내 Z-score

```
Z-score = (해당 종목 값 - 업종 평균) / 업종 표준편차
```

같은 업종 안에서만 상대 비교해 업종 편향을 제거한다.

```
예시:
반도체 업종 PER 평균 25, 표준편차 8
  A종목 PER 17 → Z-score = (17-25)/8 = -1.0 → 업종 내 저평가

유틸리티 업종 PER 평균 12, 표준편차 3
  B종목 PER 10 → Z-score = (10-12)/3 = -0.67 → 업종 내 저평가
```

두 종목이 서로 다른 업종이어도 같은 기준으로 비교 가능해진다.

- **필요 조건**: 1단계에서 수집한 업종코드(`induty_code`)
- **구현**: 업종코드 있으면 코드 변경만으로 적용 가능

## 4단계 — 가중 합산

팩터별 Z-score에 가중치를 곱해 최종 스코어 산출.

---
===============================================================================

### 가중치 (멀티팩터 구성)
예시 비율 — 실제 가중치는 백테스팅 또는 투자 철학 합의 후 결정.
Graham Number는 PER(EPS)·PBR(BPS)과 재료가 겹쳐 제외. ROA·ROE는 함께 쓸 때 레버리지 의존도 확인이 가능해 둘 다 유지.

| 카테고리 | 지표 | 가중치 | 설명 |
|----------|------|--------|------|
| 가치 | PER | 25% | 주가 ÷ EPS — 이익 대비 주가가 얼마나 비싼지 |
| 가치 | PBR | 15% | 주가 ÷ BPS — 순자산 대비 주가가 얼마나 비싼지 |
| 퀄리티 | ROE | 20% | 순이익 ÷ 자본총계 — 주주 돈으로 얼마나 버는지 |
| 퀄리티 | ROA | 10% | 순이익 ÷ 자산총계 — ROE 높고 ROA 낮으면 빚으로 수익률을 부풀린 회사 |
| 퀄리티 | 부채비율 | 15% | 부채총계 ÷ 자본총계 — 빚이 얼마나 많은지 |
| 퀄리티 | EPS 성장률 | 5% | (최근EPS ÷ 3년전EPS)^(1/3) - 1 — 수익이 꾸준히 늘고 있는지 |
| 모멘텀 | 12-1 모멘텀 | 10% | (1개월전 종가 - 12개월전 종가) ÷ 12개월전 종가 — 주가가 오르는 방향인지 |
| **합계** | | **100%** | |

- 가치 팩터 = 지금 얼마나 싸냐
- 퀄리티 팩터 = 기업이 얼마나 좋냐
- 모멘텀 팩터 = 지금 오르는 방향이냐


> 가중치는 백테스팅 결과 또는 투자 철학 합의 후 결정. 근거 없이 수치만 바꾸면 "왜 이 가중치냐"는 질문이 계속 나온다.

### 퀄리티 팩터 (Quality Factor)
- ** "이 기업이 돈을 잘 버는 좋은 회사냐"를 수치화한 것
## 12-1 모멘텀
- ** 순수 가치투자 시스템을 만들 거라면 → 모멘텀 빼는 게 맞음
- ** 가치함정 방어까지 하는 멀티팩터 시스템을 만들 거라면 → 넣는 게 맞음
- ** 주가시세 한번에 오늘,1개월전,12개월전 주가 데이터 필요
  - 모멘텀 = (1개월 전 종가 - 12개월 전 종가) / 12개월 전 종가
- ** "주가가 오르는 방향으로 가고 있냐"를 수치화한 것

#### Graham Number 편입 방식 비교

Graham Number = √(22.5 × EPS × BPS) — EPS와 BPS를 모두 사용하므로 기존 PER(EPS 기반)·PBR(BPS 기반)과 재료가 겹침.

**A안 — PBR을 Graham Number 저평가율로 교체 (추천)**

| 지표 | 방향 | 점수 |
|------|------|------|
| PER | 낮을수록 | 30점 |
| Graham Number 저평가율 | 높을수록 | 30점 |
| ROE | 높을수록 | 25점 |
| 부채비율 | 낮을수록 | 15점 |

- PBR의 BPS가 Graham Number에 이미 포함 → 중복 제거
- "현재가가 적정주가보다 X% 싸다"로 직관적 설명 가능
- 지표 4개 유지로 설명 단순

**B안 — PBR 유지하고 Graham Number 추가 (5개 지표)**

| 지표 | 방향 | 점수 |
|------|------|------|
| PER | 낮을수록 | 25점 |
| PBR | 낮을수록 | 15점 |
| Graham Number 저평가율 | 높을수록 | 25점 |
| ROE | 높을수록 | 25점 |
| 부채비율 | 낮을수록 | 10점 |

- BPS가 PBR과 Graham Number 양쪽에 반영 → 자산가치 과중 위험
- 자산가치를 더 강조하고 싶을 때 선택

## Z-score로 최종 점수 내는 방법

### Z-score = 그 자체가 점수

Z-score는 "이 종목이 업종 평균에서 얼마나 떨어져 있냐"를 표준화한 숫자다. 변환 없이 그 값 자체를 점수로 쓴다.

- **낮을수록 유리한 지표** (PER, PBR, 부채비율): Z-score에 **-1을 곱한다**
  - PER이 업종 평균보다 낮으면 Z-score가 음수 → -1 곱하면 양수 → 고점수
- **높을수록 유리한 지표** (ROE, ROA, Graham 저평가율): Z-score 그대로 사용
  - ROE가 업종 평균보다 높으면 Z-score가 양수 → 그대로 고점수

### 최종 점수 계산 예시

A종목이 반도체 업종에 속할 때:

| 지표 | Z-score | 부호 처리 | 가중치 | 기여점수 |
|------|---------|-----------|--------|---------|
| PER | -1.5 (업종 내 저평가) | × -1 = **+1.5** | 20% | +0.30 |
| Graham Number 저평가율 | +0.8 | 그대로 **+0.8** | 20% | +0.16 |
| ROE | +1.2 | 그대로 **+1.2** | 15% | +0.18 |
| ROA | +0.5 | 그대로 **+0.5** | 10% | +0.05 |
| 부채비율 | -0.9 (업종 내 낮음) | × -1 = **+0.9** | 10% | +0.09 |

```
최종 점수 = Σ (보정된 Z-score × 가중치)
          = 0.30 + 0.16 + 0.18 + 0.05 + 0.09
          = 0.78
```

### 현재 방식(0~100 정수)과 비교

| | 현재 (백분위 정수) | Z-score 방식 |
