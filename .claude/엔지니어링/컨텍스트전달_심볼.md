# AI는 내 프로젝트를 모른다

> VIBE CODING · 05 · 컨텍스트 전달 (@ 심볼)

결과 품질은 컨텍스트 8할, 프롬프트 2할. AI에게 "무엇을 보고 판단해야 하는지" 정확히 짚어주는 `@` 심볼의 기술.

---

## 01. 왜 컨텍스트가 전부인가

AI는 똑똑하지만 **내 프로젝트를 모릅니다.** 같은 요청도 컨텍스트가 있고 없고에 따라 결과가 완전히 달라집니다.

| 컨텍스트 | 결과 |
|----------|------|
| 없이 요청 | 일반적이고 엉뚱한 코드 |
| 관련 파일·문서·규칙 첨부 | **내 코드 스타일에 맞는 정확한 코드** |

컨텍스트를 붙이는 관문이 `@`입니다. Chat/Agent 입력창에서 `@`를 누르면 붙일 수 있는 목록이 뜹니다.

---

## 02. 핵심 @ 심볼

| @ 심볼 | 붙는 것 | 쓰는 상황 |
|--------|---------|-----------|
| `@파일명` | 특정 파일 전체 | "이 파일 기준으로 고쳐줘" |
| `@폴더명` | 폴더 안 파일들 | 관련 모듈 묶어 참고 |
| `@Codebase` | 프로젝트 전체 검색 | "이 기능 어디서 처리해?" |
| `@Docs` | 라이브러리 공식 문서 | 최신 API 사용법 |
| `@Web` | 실시간 웹 검색 | 최신 정보·에러 검색 |
| 이미지 첨부 | 스크린샷·목업 | "이 디자인처럼 만들어줘" |

> **팁** — 버전에 따라 명칭이 조금씩 다를 수 있습니다. `@`만 눌러 그때그때 가능한 목록을 확인하세요.

---

## 03. 상황별 활용

- **내 스타일 따르게** — "`@Button.tsx` 와 똑같은 패턴으로 Input 컴포넌트를 만들어줘."
- **전체에서 찾기** — "`@Codebase` 로그인 처리는 어디서 하고 세션은 어떻게 저장돼?"
- **최신 문서 참고** — "`@Docs` Next.js App Router로 폼 처리 예제 만들어줘."
- **이미지로 만들기** — 목업을 붙이고 "이 화면을 HTML/CSS로 구현해줘."

---

## 04. 컨텍스트 위생

- **필요한 것만 붙여라.** 관련 없는 파일을 잔뜩 붙이면 오히려 AI가 헷갈립니다.
- 큰 작업엔 `@Codebase`, 정밀 작업엔 특정 `@파일`.
- 답이 엉뚱하면 → **"컨텍스트가 부족한가?"** 를 먼저 의심.

> **정리** — 바이브코딩의 결과는 **어떤 컨텍스트를 담느냐**로 갈린다. `@`로 관련 파일·문서를 **딱 필요한 만큼** 붙이는 것이 실력이다.

---

## 직접 따라하기 — 룰북 실습

견본 파일 `Button.js`를 만들어 붙여넣고, 그 스타일을 따라 새 컴포넌트를 만들게 해보세요.

**1) 견본 Button.js 붙여넣기**

```javascript
// Button 컴포넌트 (함수형 + 기본값 props + 한국어 주석 + 맨 아래 export)
/**
 * 클릭 가능한 버튼을 만든다.
 * @param {string} label - 버튼 글자
 * @param {function} onClick - 클릭 시 실행
 */
function Button(label, onClick, variant = "primary") {
  const el = document.createElement("button");
  el.className = "btn btn-" + variant;
  el.textContent = label;
  el.addEventListener("click", onClick);
  return el;
}
export default Button;
```

**2) @파일로 스타일 따라 만들기 (채팅에 붙여넣기)**

```
@Button.js 이 파일과 똑같은 패턴(주석 스타일, 구조, 맨 아래 export)으로
Input.js 컴포넌트를 만들어줘. 텍스트 입력을 받고 placeholder를 인자로 받게.
```

**3) @Codebase로 프로젝트 탐색**

```
@Codebase 이 프로젝트에는 어떤 컴포넌트가 있고 각각 무슨 역할이야? 표로 정리해줘.
```
