# 일하는 동료, 에이전트

> VIBE CODING · 04 · Agent 모드 (Composer) · 기본기

여러 파일을 스스로 계획하고, 만들고, 실행하고, 에러가 나면 고치는 Agent. "한 문장 → 동작하는 앱"이 여기서 일어납니다.

---

## 01. Agent란

**Agent(Composer)** 는 여러 파일에 걸친 작업을 **스스로 계획하고 실행**하는 모드입니다. Chat이 "대화"라면 Agent는 "일하는 동료"에요. 열기는 `Ctrl + I`.

- 파일 **생성·수정·삭제**를 알아서 함
- 터미널 **명령 실행**(`npm install` 등)을 제안·실행
- 에러가 나면 **읽고 스스로 고침**(자동 반복)

---

## 02. 작업 흐름

```
  ① 계획 수립
        │
        ▼
  ② 파일 생성/수정(diff)
        │
        ▼
  ③ 명령 실행(승인)  ◀─┐
        │             │ ③·④ 반복
        ▼             │
  ④ 결과 확인·자가 수정 ─┘
        │
        ▼
  ⑤ 내가 Accept/추가요청
```

요청 → 계획 → 편집 → 실행 → 검증 → 사람 확인. ③·④ 사이를 스스로 반복하기도 한다.

> **주의** — Agent가 **터미널 명령을 실행할 때는 승인**을 물어봅니다. 낯선 명령(파일 삭제 등)은 내용을 확인하고 승인하세요.

---

## 03. 승인 & 되돌리기

- **Accept / Reject** — 각 변경을 개별 또는 일괄 수락/거절
- **체크포인트** — Agent는 작업 단계마다 스냅샷을 남깁니다. 마음에 안 들면 **이전 체크포인트로 복귀**(08강 Git과 함께 쓰면 더 안전)
- 방향이 틀어지면 즉시 멈추고 **"방금 건 되돌리고, 대신 ~하게 해줘"**

---

## 04. Agent를 잘 쓰는 3원칙

1. **한 번에 하나씩** — "다 만들어줘"보다 기능 단위로 쪼갠다.
2. **결과를 항상 실행해 확인** — 눈으로 봐야 다음 지시가 정확해진다.
3. **막히면 되돌리고 다시** — 엉킨 상태를 억지로 고치기보다 체크포인트 복귀.

> **정리** — Agent = 계획·편집·실행·자가수정을 하는 자동 동료. 사람은 **범위를 쪼개고, 결과를 확인하고, 방향을 잡는** 감독 역할.

---

## 직접 따라하기 — 룰북 실습

`Ctrl + I`로 Agent를 열고, 아래 프롬프트를 하나씩 복사해 붙여넣으세요. (빈 `todo-앱` 폴더에서)

**1) 첫 앱 만들기**

```
바닐라 HTML/CSS/JavaScript로 간단한 할 일 목록(To-Do) 웹앱을 만들어줘.
- 할 일 추가 / 완료 체크 / 삭제 기능
- 브라우저 localStorage에 저장돼서 새로고침해도 유지
- 깔끔한 반응형 디자인, 외부 라이브러리 없이
- 파일은 index.html, style.css, script.js 로 나눠줘
다 만들면 브라우저에서 여는 방법도 알려줘.
```

→ 파일 diff를 확인하고 Accept → 브라우저로 열어 동작 확인!

**2) 개선 요청 (하나씩, 매번 확인)**

```
완료 체크한 항목은 취소선과 회색으로 표시해줘.
```

```
오른쪽 위에 다크 모드 토글 버튼을 추가해줘. 선택은 localStorage에 저장되게.
```

**3) 되돌리기 연습**

```
방금 변경은 되돌려줘. 이전의 깔끔한 디자인으로.
```
