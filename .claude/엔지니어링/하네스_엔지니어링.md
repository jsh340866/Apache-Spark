# AI를 감싸는 시스템

> VIBE CODING · 14 · 하네스 엔지니어링 · 필수

모델은 "두뇌" 하나일 뿐. 그 두뇌에 도구를 쥐어주고, 결과를 확인하고, 상태를 기억하고, 위험을 막는 "몸통"이 하네스입니다. Cursor·Claude Code가 잘 되는 진짜 이유.

---

## 01. 하네스란

**에이전트 하네스(agent harness)** 는 LLM을 둘러싸고 작업의 생애주기를 관리하는 시스템 전체입니다. 모델에 도구를 연결하고, 매 단계 어떤 컨텍스트를 넣을지 정하고, 허용된 행동을 강제하고, 세션 상태를 저장합니다.

> **비유** — LLM이 뛰어난 요리사의 두뇌라면, 하네스는 **주방 전체**입니다 — 재료를 꺼내오고(도구), 맛을 보고(검증), 레시피를 기억하고(상태), 불을 안전하게 관리하는(권한) 시스템. 두뇌만 좋아선 요리가 안 나와요.

---

## 02. 핵심 루프 — 생각·행동·관찰

하네스의 심장은 **ReAct 루프**(생각→행동→관찰)입니다. 04강 Agent가 실제로 이 루프를 돕니다.

```
        ┌─────────────────────┐
        ▼                     │
  ① 생각 (계획)               │
        │                     │
        ▼                   반복
  ② 행동 (도구 실행)          │
        │                     │
        ▼                     │
  ③ 관찰 (결과 확인) ─────────┘
```

계획 → 도구 실행 → 결과 관찰 → 다시 계획. 작업이 끝날 때까지 이 고리를 돈다.

이 루프 덕분에 "테스트 실행 → 실패 → 원인 파악 → 수정 → 재실행"이 **자동으로** 이어집니다.

---

## 03. 하네스의 5가지 일

| 역할 | 하는 일 | 관련 강 |
|------|---------|---------|
| 컨텍스트 관리 | 매 단계 무엇을 넣을지 결정·압축 | 13 |
| 도구 연결 | 파일·터미널·MCP 등 실행 통로 | 04·10 |
| 검증 | 결과가 맞는지 확인(테스트·리뷰) | 09·17 |
| 상태 유지 | 세션 간 결정·진행 저장 | 메모리 |
| 권한·안전 | 허용된 행동만, 위험은 승인 | 18 |

> **참조** — Cursor의 Agent, Claude Code, Claude Agent SDK가 모두 "하네스"입니다. 우리가 좋은 결과를 얻는 건 모델뿐 아니라 이 하네스가 잘 만들어졌기 때문.

---

## 04. 초보가 하네스를 "돕는" 법

하네스를 직접 만들진 않아도, 그것이 잘 돌게 **재료를 잘 주는** 건 사용자 몫입니다.

- **검증 통로를 준다** — 테스트·실행 방법을 알려주면 스스로 고침(09).
- **되돌릴 지점을 만든다** — Git 커밋으로 안전지대 확보(08).
- **권한을 확인한다** — 위험한 실행 승인은 신중히(18).
- **작업을 쪼갠다** — 루프가 헤매지 않게 작은 목표로(07).

> **정리** — 하네스 = 모델(두뇌)을 감싸 도구·검증·상태·안전을 관리하는 몸통. 좋은 결과는 모델과 하네스의 합작이며, 사용자는 그 루프에 좋은 재료를 준다.

## 직접 따라하기 — 룰북 실습

하네스가 잘 돌게 "재료"를 주는 프롬프트를 연습해보세요. (Agent 모드)

**1) 검증 통로 주기 (자가 수정 유도)**

```
이 기능을 구현하고, 테스트를 작성해 실행해줘. 테스트가 통과할 때까지
스스로 고쳐줘. 각 시도마다 무엇을 바꿨는지 한 줄로 알려줘.
```

**2) 진행 상태를 남기게 하기 (상태 유지)**

```
지금까지 진행 상황과 다음 할 일을 progress.md 파일에 체크리스트로
정리해줘. 작업하면서 계속 업데이트해줘.
```

**3) 권한 경계 확인 (안전)**

```
파일을 삭제하거나 외부로 데이터를 보내는 명령은 실행하기 전에
반드시 먼저 나에게 무엇을 왜 하는지 물어봐.
```

> 이 세 가지(검증·상태·권한)가 하네스가 잘 돌게 하는 핵심 재료입니다.
