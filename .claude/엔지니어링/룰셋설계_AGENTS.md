# 기계를 위한 사규(社規)

> VIBE CODING · 15 · 룰셋 설계 & AGENTS.md · 필수

06강의 Rules를 "아키텍처"로 끌어올립니다. 프로젝트의 규칙을 어떻게 계층화하고, 2025년 업계 표준이 된 `AGENTS.md`로 어떻게 정리하는지 — 여러 AI 도구가 공유하는 "기계용 README".

---

## 01. 룰셋이란 — 규칙의 "묶음"

06강에서 규칙 하나를 배웠다면, **룰셋(rule set)** 은 규칙들을 **주제별로 나눠 체계적으로 관리**하는 것입니다. 코딩 스타일, 폴더 구조, API 규칙, 보안 규칙을 각각의 파일로 정리해요.

> **비유** — 규칙 한 줄이 **포스트잇**이라면, 룰셋은 **잘 정리된 사규집**입니다. 신입(AI)이 언제든 펼쳐볼 수 있게, 목차를 나눠 정리해 둡니다.

---

## 02. AGENTS.md — 기계용 README

`AGENTS.md`는 2025년 8월 OpenAI·Google·Cursor·Sourcegraph 등이 함께 만든 **오픈 표준**으로, 2만 개 넘는 저장소가 채택했습니다. 프로젝트 루트에 두는 마크다운 파일로, AI 코딩 도구가 **공통으로 읽는** 지침서예요.

| 파일 | 읽는 도구 |
|------|-----------|
| `AGENTS.md` | Cursor·Copilot·Codex·Windsurf 등 25종+ |
| `CLAUDE.md` | Claude Code (자체 형식) |
| `.cursor/rules` | Cursor 전용 규칙(06강) |

> **참조** — "사람용 README"가 있듯, **"기계용 README"가 AGENTS.md**. 빌드·테스트 명령, 코드 스타일, 하지 말 것을 적어두면 어떤 AI 도구든 더 잘 돕습니다.

---

## 03. AGENTS.md 권장 구성

```markdown
# 프로젝트 개요
간단한 프로젝트 설명 (무엇을 하는 앱인가)

# 빌드 · 실행 · 테스트
- 설치: npm install
- 개발: npm run dev
- 테스트: npm test

# 코드 스타일
- TypeScript, 함수형 컴포넌트, Tailwind
- 주석·커밋 메시지는 한국어

# 하지 말 것
- .env 파일 커밋 금지
- 임의로 새 라이브러리 추가 금지 (먼저 물어볼 것)

# 커밋 · PR 규칙
- 커밋 메시지: "타입: 설명" 형식
```

핵심 섹션: **개요 · 빌드/테스트 명령 · 코드 스타일 · 보안 · 커밋 규칙 · 금지 사항.**

---

## 04. 규칙을 잘 쓰는 원칙

- **구체적으로** — "좋게 해줘" / "함수는 20줄 이내"
- **금지도 명시** — "~하지 마라"가 특히 효과적
- **짧고 핵심만** — 너무 길면 AI가 다 못 지킴
- **주제별로 분리** — 스타일·구조·보안을 각각

> **정리** — 룰셋 = 규칙을 주제별로 정리한 사규집. 여러 도구가 공유하는 표준은 `AGENTS.md`, Cursor 전용 세부는 `.cursor/rules`로 둔다.

## 직접 따라하기 — 룰북 실습

프로젝트 루트에 `AGENTS.md` 파일을 만들고 아래 뼈대를 붙여넣어 나만의 룰셋을 시작하세요.

**1) AGENTS.md 뼈대 붙여넣기**

```markdown
# 프로젝트 개요
(무엇을 하는 앱인지 한 줄)

# 빌드 · 실행 · 테스트
- 설치: npm install
- 개발: npm run dev
- 테스트: npm test

# 코드 스타일
- TypeScript, 함수형 컴포넌트, Tailwind
- 주석·커밋 메시지는 한국어

# 하지 말 것
- .env 파일 커밋 금지
- 새 라이브러리 추가 전 반드시 물어볼 것

# 커밋 규칙
- 형식: "타입: 설명" (예: feat: 로그인 추가)
```

**2) AI에게 내 프로젝트용 AGENTS.md 만들게 하기**

```
@Codebase 이 프로젝트를 분석해서, 빌드/테스트 명령·코드 스타일·금지사항을
담은 AGENTS.md을 만들어줘. 핵심만 40줄 이내로.
```

**3) Cursor 전용 세부 규칙 — `.cursor/rules/react.mdc`**

프로젝트에 `.cursor/rules/` 폴더를 만들고 아래를 `react.mdc`로 저장하세요. React 파일을 열 때만 자동으로 붙습니다(Auto Attached).

```markdown
---
description: React 컴포넌트 작성 규칙
globs: src/**/*.{tsx,jsx}
alwaysApply: false
---

# 컴포넌트 규칙
- 함수형 컴포넌트 + 훅만 사용 (클래스 컴포넌트 금지)
- 파일 1개 = 컴포넌트 1개, 이름은 PascalCase
- props 타입은 interface로, any 금지
- 스타일은 Tailwind 유틸리티 우선
```

> 규칙은 **"짧고 구체적으로"**. 방대한 지식은 규칙이 아니라 MCP(10강)로! 대부분의 세부 규칙은 **glob으로 자동 첨부**해 상시 프롬프트를 가볍게.
